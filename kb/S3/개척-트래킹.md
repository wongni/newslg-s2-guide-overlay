# S3 개척 트래킹 (점령·개간 중심 · 저돌파 기준)

> 목적: 개척1/2/3이 **개간·점령·소탕**을 할 때마다 한 줄씩 기록해, **개간지/점령지 현황(몇 레벨 몇 개)** 과 각 부대 레벨·체력 변화를 하나의 표로 추적.
> 건설/건물 레벨업 퀘스트는 제외 (개척 행동만 추적). 원본: `개척가이드.md`, 경험치: `../../docs/level-exp.md`
> **저돌파 기준**: 6레벨 토지 21렙↑ / 7레벨 26렙↑ / 8레벨 31렙↑ 도전.

---

## ⚠️ 이 문서를 업데이트할 때 꼭 알아야 할 규칙 (새 세션 필독)

### 1. 게임 메커니즘
- **개간**: `LvN 개간지`를 개간하면 → **LvN+1 수비군**과 전투 → 개간지가 `LvN+1`이 됨.
  - "대상" 컬럼은 **개간 전(입력) 레벨** 기준으로 표기. 예: `Lv4 ×1`은 Lv4→Lv5로 만드는 개간.
  - **획득 경험치는 결과(LvN+1) 토지값**. 예: Lv4 개간(→Lv5 완성) = Lv5 토지값 12000.
- **점령**: `LvN 외성토지`를 점령하면 → **LvN 수비군**과 전투 → LvN 토지 획득. 경험치 = **LvN 토지값**.
- **소탕**: 이미 점령한 토지를 전투만 해서 **경험치만** 얻음. **영지·개간지 수 변화 없음**. 경험치 = 해당 토지 레벨값.
- **둔전**: 자원만 획득. 부대 경험치·체력 변화 없음.

### 2. 경험치 → 소수점 레벨 계산 (가장 실수 잦은 부분)
- 각 부대의 경험치는 **누적**으로 관리한다. 절대 행마다 독립 계산하지 말 것.
- 레벨 = `정수레벨 + (누적경험치 − 그 레벨 도달 누적선) / 다음 레벨 필요경험치`.
- **누적 경험치 기준선(5레벨=0부터)**: 부록 A 표를 반드시 참조. 특히 20레벨 도달선은 **270000** (230000 아님 — 과거 반복된 오류).
  - 주요 누적선: Lv15=90000, Lv16=118000, Lv17=150000, Lv18=186000, Lv19=226000, **Lv20=270000**, Lv21=350000, Lv22=446000, Lv23=560000, Lv24=694000, Lv25=852000, Lv26=1044000, Lv27=1264000, Lv28=1516000, Lv29=1804000, Lv30=2132000.
- **70% 규칙**: 부대 레벨 < 토지의 "100% 최소 부대레벨"이면 획득 경험치 ×0.7 (부록 A 참조).
  - Lv6→19렙, Lv7→24렙, Lv8→29렙. 이 레벨 이상이면 전액.

### 3. 체력 소모 규칙 (결과 토지 레벨 기준)
- 결과 **Lv3 이하 = 10 소모**, 결과 **Lv4 이상 = 20 소모**.
- **닭다리**: 부대당 +60. 챕터 완료로 획득(2~7장 각 2, 8·9장 3, 10장 4). 사용 시 닭다리 열 −1, 체력 +60.
- 닭다리 사용은 "체력이 0 이하로 떨어지기 직전에 최소 개수만" 배치해 계산.
- **10장까지 자연회복 없음**. 4시간 경과 후부터 자연회복 시간당 20(3분당 1) + 자원 생산 시작.

### 4. 부대 재편성
- 전법 초기화·퇴진·교체 시에도 **레벨(누적 경험치)과 체력은 유지**된다.
- 단, "5레벨/체력200 새 장수 편성"처럼 **명시적으로 새 장수를 넣으면 5.0/200으로 리셋**.

### 5. 한도 증가
- **개간지 한도 +2**: 챕터 완료 보상. 신규 개간지는 **기존 개간지의 최소 레벨로 생성**(추정, 각주 ᵏ).
- **영지(점령) 한도**: 번영도 퀘스트로 증가 — 6장 번영4500 +2(→12), 7장 번영10000 +2(→14), 8장 번영15000 +3(→17), 10장 번영20000 +3(→20).
- 한도 변화 행은 부대 값 `-`로 두고 현황의 (사용/한도)만 갱신.

### 6. 표 작성 원칙
- 한 부대가 움직인 행은 그 부대 컬럼만 값 기입, 나머지는 `-`.
- 현황 표기 `LvX×N` 개수 합 = 사용량과 일치, 사용량 ≤ 한도 (초과 시 오류).
- 새 행을 중간에 끼우면 **이후 같은 부대의 누적 경험치·체력·닭다리가 전부 밀리므로 연쇄 재계산** 필요.
- 값 수정 후에는 반드시 개간지·점령지 개수 합과 한도를 검산.

**각주**
- ⁿ 누적 경험치 기준: 2레벨 토지 2560×4 = 10240 → 5.0에서 8레벨 도달 후 1240/5000 = **8.25** (실측 8레벨).
