## 전법 정보

| 항목 | 내용 |
|------|------|
| 전법 이름 | 무장 사살 |
| 전법 레벨 | 10레벨 (최고 레벨) |
| 전법 유형 | 추격 |
| 전법 특성 | 병기 |
| 적합 병종 | 미확인 (스크린샷 적합 병종란에 단일 아이콘이 비활성(빗금) 표시로만 보여 병종 특정 불가) |
| 발동률 | 45% |

---

## 전법 설명

일반 공격 후, 해당 목표에게 50%→100%의 병기 피해를 주며, 목표의 선공이 50→100포인트 이하면 이번 피해가 25% 증가한다.
