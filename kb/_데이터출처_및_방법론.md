# 전법 데이터 출처 및 방법론

## 개요

이 kb 폴더의 전법 수치 데이터는 **게임 클라이언트(삼국지: 천하결전) 내부 데이터**에서 직접 추출한 것입니다.
웹 공략(biligames)의 값은 대부분 **1레벨(기본)** 수치였으나, 이 문서들의 값은 **10레벨(만렙)** 실제값입니다.

## 추출 방법

게임의 AssetBundle(`.ns` 파일)은 UnityFS 컨테이너 + LZ4 블록 압축(표준)이지만, 내부 SerializedFile payload는 **자체 암호화**되어 있어 정적 파일 파싱으로는 읽을 수 없었습니다. IL2CPP 메타데이터(`global-metadata.dat`)도 헤더가 변형되어 있습니다.

게임은 실행 시 데이터를 복호화해 메모리에 올리므로(`AssetBundle.LoadFromMemory` 사용), **실행 중인 프로세스 메모리에서 복호화된 평문 텍스트를 읽어** 추출했습니다.
- 접근 방식: 읽기 전용(`PROCESS_VM_READ`), 코드 주입·변조 없음
- 관리자 권한 필요 (안티치트 모듈로 인해 일반 권한 OpenProcess 거부됨)
- 도구 스크립트: `../tools/mem_extract.py`, `../tools/parse_skills.py`

## 수치 공식

게임 원본 텍스트는 레벨 성장 공식을 다음 형식으로 저장합니다:
- `$base + giver.skillLv*step$` — 뒤에 `%`가 붙으면 백분율
- **만렙(10레벨) 값 = (base + step × 10)**, 백분율이면 ×100
- `giver.skillLv` 최대값 = **10** (교차검증 완료: 조운 칠진칠출 피신 `0.175+0.0175×10=0.35=35%`, 용담 `0.45+0.045×10=0.90=90%`)
- `step`이 0이면 성장 없음(레벨 무관 고정값)
- `@...@` 표기도 동일 계산 (일부 전법)
- `giver.skillClass`(병종/전법 등급 의존) 변수는 계산 불가하여 원본 표기 유지

## 주의사항

- `전법_전체_원본데이터_만렙.txt`에는 전법명·무장명이 붙어있지 않습니다(게임 내부에서 이름 테이블과 설명 테이블이 분리 저장). 특정 전법을 찾으려면 효과 문구로 검색하세요.
- 일부 라인은 게임 데이터 자체의 표기 오류(예: 포인트값에 `%`가 잘못 붙어 큰 수로 계산됨)를 포함할 수 있습니다.
- 이 데이터는 개인 참고용 정리이며, 게임 업데이트 시 값이 변경될 수 있습니다.
