# 네비게이션 & 레이아웃 디자인 방안

## 현재 문제점
- 헤더에 버튼이 너무 많아 모바일에서 세로 회전됨
- 각 기능 페이지 이동 시 "돌아가기" 필요 → SPA 느낌 부족
- 유저 메뉴, 가이드 소스 선택 등이 한 줄에 몰려있음

---

## 방안 A: 하단 탭바 (모바일 앱 스타일)

```
┌─────────────────────────────────────────────┐
│ 삼국지 천하결전 S2 가이드       [☀️] [온달]  │  ← 미니 헤더
├─────────────────────────────────────────────┤
│                                             │
│           (메인 콘텐츠 영역)                  │
│         선택된 탭에 따라 변경                  │
│                                             │
│                                             │
├─────────────────────────────────────────────┤
│  📋      ✏️      🌐      🛤️     ⚔️     ⚙️  │  ← 하단 탭바
│ 가이드  나의    커뮤   길작   상성   더보기  │
└─────────────────────────────────────────────┘
```

**모바일**: 하단 탭바 고정, 한 손 조작 최적
**데스크톱**: 하단 탭바 → 상단 수평 탭으로 전환 (또는 유지)

더보기 탭: ROI, 계산기, 오버레이, 설정 등 묶음

**장점**: 모바일 네이티브 앱 느낌, 엄지 접근성, 한 화면에서 전환
**단점**: 탭 수 제한 (5~6개), 데스크톱에서 공간 낭비 가능

---

## 방안 B: 상단 수평 스크롤 탭 (모바일 웹 표준)

```
┌─────────────────────────────────────────────┐
│ S2 가이드                    [☀️] [온달 ▾]  │  ← 헤더
├─────────────────────────────────────────────┤
│ [가이드] [나의] [커뮤니티] [길작] [상성] [ROI] [계산기] │  ← 스크롤 탭
├─────────────────────────────────────────────┤
│                                             │
│           (메인 콘텐츠 영역)                  │
│                                             │
└─────────────────────────────────────────────┘
```

**모바일**: 탭 바가 수평 스크롤 (손가락으로 밀기), 활성 탭 밑줄
**데스크톱**: 모든 탭이 한 줄에 보임

**장점**: 확장성 좋음 (탭 무제한 추가 가능), 유튜브/인스타 스타일로 익숙
**단점**: 탭이 많으면 오른쪽이 숨겨져서 발견성 낮음

│ 📈 ROI  │                                    │
│ 🧮 계산기│                                    │
│        │                                    │
│ ───── │                                    │
│ [온달]  │                                    │

**장점**: 기능이 많아져도 깔끔, 프로 도구 느낌
**단점**: 모바일에서 햄버거 메뉴는 발견성 낮음, 게임 가이드엔 과한 느낌

## 방안 D: 아이콘 그리드 홈 + 풀스크린 기능 (허브 스타일)

```
홈 화면 (허브):
┌─────────────────────────────────────────────┐
│ S2 개척 가이드                  [☀️] [온달]  │
├─────────────────────────────────────────────┤
│                                             │
│  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐   │
│  │ 📋   │  │ ✏️   │  │ 🌐   │  │ 🛤️   │   │
│  │가이드 │  │나의  │  │커뮤  │  │길작   │   │
│  └──────┘  └──────┘  └──────┘  └──────┘   │
│  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐   │
│  │ ⚔️   │  │ 📈   │  │ 🧮   │  │ 🖥️   │   │
│  │상성표 │  │ROI   │  │계산기 │  │오버레이│   │
│  └──────┘  └──────┘  └──────┘  └──────┘   │
│                                             │
└─────────────────────────────────────────────┘

기능 선택 후:
┌─────────────────────────────────────────────┐
│ [← 홈] 가이드                  [☀️] [온달]  │
├─────────────────────────────────────────────┤
│                                             │
│           (기능별 풀스크린 콘텐츠)             │
│                                             │
└─────────────────────────────────────────────┘
```

**장점**: 기능 발견성 최고, 확장 무제한, 모바일/데스크톱 동일
**단점**: 홈 → 기능 간 이동이 한 단계 더 필요, SPA 느낌 약함

## 추천 방안: A + B 하이브리드

```
데스크톱 (>768px):
┌─────────────────────────────────────────────────────────┐
│ S2 개척 가이드   [가이드][나의][커뮤니티][길작][상성][ROI][계산기]  [☀️][온달▾] │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                  (메인 콘텐츠 영역)                        │
│                                                         │
└─────────────────────────────────────────────────────────┘

모바일 (<768px):
┌─────────────────────────────────────────────┐
│ S2 가이드                      [☀️] [온달]  │
├─────────────────────────────────────────────┤
│                                             │
│           (메인 콘텐츠 영역)                  │
│                                             │
├─────────────────────────────────────────────┤
│  📋     ✏️     🌐     🛤️     ⚔️     •••   │  ← 고정 하단 탭
│ 가이드  나의  커뮤  길작   상성  더보기      │
└─────────────────────────────────────────────┘
```

- 데스크톱: 상단 수평 탭 (모두 노출)
- 모바일: 하단 고정 탭바 (주요 5개 + 더보기)
- 페이지 전환 없이 컨텐츠 영역만 교체 (SPA)
- 가이드 소스 선택/티어 선택은 가이드 탭 내부 서브 컨트롤로 이동

**이게 좋은 이유:**
- 모바일: 엄지 영역에 네비게이션, 네이티브 앱 느낌
- 데스크톱: 한눈에 모든 기능 보임
- SPA: URL은 바뀌지만 레이아웃 유지 (Next.js layout 활용)
- 확장성: 기능 추가 시 "더보기"에 넣으면 됨
