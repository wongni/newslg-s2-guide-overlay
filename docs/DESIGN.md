# S2 개척 가이드 오버레이 앱 설계

## 개요

삼국지 천하결전 S3(글로벌 S2) 개척 가이드를 게임 플레이 중 오버레이 윈도우로 표시하는 웹 앱.
POE2WAY의 Act Guide Overlay를 참조하되, 액트 구분 없이 단일 진행 루트이므로 더 단순한 구조를 채택한다.

## 핵심 기능

### 1. 메인 페이지 (관리 화면)
- 전체 개척 단계 목록을 카드로 표시
- 각 단계 카드 클릭 시 상세 내용 확장 (Purpose, 조건, 주의사항, 팁)
- 단계별 완료 체크 (번호 버튼 클릭으로 토글)
- 전체 진행률 프로그레스 바
- "오버레이 열기" 버튼 → 별도 팝업 윈도우

### 2. 오버레이 윈도우 (핵심)
게임 위에 올려놓는 작은 별도 브라우저 윈도우.

**구성:**
```
┌─────────────────────────────────────┐
│ 삼국 S2 개척 가이드    3/22 · 14%   │
├─────────────────────────────────────┤
│ ✓ 01  1단계: 내성 1→2레벨          │
│ ✓ 02  2단계: 도원 부대 편성         │
│ ✓ 03  3단계: 메인 퀘스트 6장       │
│ ● 04  4단계: 내성 4레벨 공격  ← 현재│
│   05  5단계: 전법 세팅              │
│   06  6단계: 외성 3레벨 점령        │
│   ...                               │
└─────────────────────────────────────┘
```

**항목 클릭 시 확장:**
```
┌─────────────────────────────────────┐
│ ● 04  4단계: 내성 4레벨 공격        │
├─────────────────────────────────────┤
│ 할 일                               │
│ • 내성에서 4레벨 땅 하나를 친다     │
│ • 도원 부대가 10레벨 도달            │
│                                     │
│ 조건                                │
│ • 전법 레벨 균등 분배 확인          │
│ • 유비/조조: 허점공략 장착          │
│                                     │
│ ⚠ 주의                              │
│ • 전법 레벨 부족 시 전복 가능성 있음│
└─────────────────────────────────────┘
```

**기능:**
- done 버튼 → 완료 토글 (완료된 항목은 흐리게 + 취소선)
- 현재 진행 항목 자동 하이라이트
- 항목 클릭 → 상세 확장/축소
- 진행률 표시
- localStorage로 진행 상태 저장 (메인 <-> 오버레이 동기화)
- 최소 크기(400x600)의 심플한 다크 테마 (게임 위 가독성)

### 3. 데이터 구조

개척 가이드를 단계별 체크리스트로 구조화:

```typescript
interface Step {
  id: number;
  phase: string;       // "1단계", "2단계", ...
  title: string;       // 짧은 제목
  tasks: string[];     // 할 일 목록
  conditions?: string[];  // 선행 조건
  warnings?: string[];    // 주의사항 (빨간 텍스트)
  tips?: string[];        // 팁 (파란 텍스트)
  rewards?: string[];     // 보상/결과
}
```

## 기술 스택

- Next.js 16 (이미 설정됨)
- Tailwind CSS 4 (이미 설정됨)
- localStorage 기반 진행 상태 저장
- BroadcastChannel API로 메인↔오버레이 실시간 동기화
- window.open()으로 오버레이 팝업 생성

## 페이지 구조

```
/                → 메인 페이지 (전체 가이드 + 관리)
/overlay         → 오버레이 전용 페이지 (팝업으로 열림)
```

## UI 테마

- 메인 페이지: 라이트/다크 테마 지원
- 오버레이: 다크 테마 고정 (반투명 배경, 게임 위 가독성 최적화)
  - 배경: rgba(15, 15, 20, 0.92)
  - 텍스트: 밝은 회색 (#e0e0e0)
  - 현재 단계 하이라이트: 황금색 테두리 (#d4a017)
  - 완료: 흐린 초록 취소선
  - 경고: 빨간색 (#ff6b6b)
  - 팁: 하늘색 (#64b5f6)

## 동기화 로직

1. 메인/오버레이 모두 localStorage에서 진행 상태를 읽고 씀
2. BroadcastChannel("s2-guide-progress")로 변경 사항을 양방향 전파
3. 어느 쪽에서든 체크하면 상대쪽도 즉시 반영
