트랜스크립트 요약 메모 (xwkgY7sCCVE - 개척 후기, 팁 공유, Q&A)

핵심 팁 추출:

1. 탐방 먼저 진행 → 동전 수급 (시즌1/2 옥석/황금으로 탐방하여 중복 시 동전 획득)
2. 상점: 
   - 일반 상점: 황금으로 동전만 구매 (자원/예비병 X)
   - 시즌 상점: 동전 → 예비병 → 랜덤 장비/말(1세트) → 병부(2개) → 상마령 + 책자
   - 동맹 상점: 동전 위주 구매
3. 초기 개척:
   - 먼저 안 쓸 장수(오자양장/보라x3)로 내성 1레벨→2레벨 개간
   - 전법 10레벨까지 올린 후 퇴진 전에 전법 초기화하여 동전 회수
   - 초기 개척덱(서대손/초체장 등) 편성 → 내성 3레벨 x4
4. 군사훈련: 1번 실패 시 중단 (보수적), 2번 연속 실패 시 중단
5. 자동 귀환 + 자동 보충 켜기 → 안정적 개척
6. 레벨별 해금:
   - 10레벨: 전법 2번째 → 파워 2배 (전법 초기화 후 평준화 필수)
   - 15레벨: 장비 착용 가능
   - 20레벨: 전법 3번째 → 또 초기화 후 평준화
   - 25레벨: 병서 해금
   - 매 10레벨: 속성 찍기 (추천 속성 그냥 저장)
7. 5급지 도전:
   - 사마가 수비군 찾기 (보라 장수 3명 + 사마가 포함)
   - 사마가가 쉬운 이유: 공포 메카닉 (한 턴 3회 피격 시 행동 불가)
   - 타수 많은 덱(채원동, 손대태 등)에 유리
   - 전복 시: 3분 대기 후 약해진 적에게 재도전 가능 (경험치도 획득)
   - 닭다리(체력60) 활용: 31레벨 전까지만 사용 가능
8. 중기 개척덱 교체:
   - 20레벨+ 되면 "퇴진"이 아니라 "교체"로 전환 (레벨 계승)
   - 교체 시 높은 장수의 체력을 이어받음
   - 후기덱: 고육궁(황계송건주유) > 손소주 > 대소주 > 도원
9. 정령: 석재 생산량 5,000/시간 증가가 가장 좋음 (석재가 가장 부족)
10. 자원 비율: 목재:철광:석재 = 1:1:1.3~1.5 (건물 업그레이드 시 석재가 30%+ 더 필요)
11. 영지 리밸런싱 팁:
    - 넘치는 자원의 토지를 포기(3분)하고 → 부족한 자원의 상급 토지를 점령
    - 타이밍 맞추면 동시에 처리 가능
    - 효과: 2,500+ 자원 차이 발생 (단순 레벨업 200 차이 vs 교체 2,500 차이)
12. 둔전:
    - 6레벨 토지까지 참기 (5레벨 vs 6레벨 차이 = 1시간~1.5시간 분량)
    - 20회까지 누적, 하루 5개
13. 퀘스트 완료 순서: 
    - 가장 빠르게 완료 가능한 것 우선
    - 단, 군왕전 같은 게이트 퀘스트는 최우선
    - 이도저도 아니면 병영 우선 (병력 상한 직접 영향)
14. 7급지+:
    - 수비군 2부대씩 등장, 앞부대만 확인 가능 (뒷부대는 전투 후 확인)
    - 견희/정보 쉬움, 서서(지뢰) 피하기
    - 레벨 25+ 추천 (고육궁은 24, 나머지는 26~27)
15. 행군 vs 주둔:
    - 행군: 단순 이동
    - 주둔: 해당 타일 + 주변 1칸 내 아군 땅 보호 (지나가는 적과 교전)
    - 수비 시 항상 주둔 사용
16. 길작(도로):
    - 잠금 기능으로 중요한 도로 보호 가능
    - 영지 교체 시 가장 낮은 레벨이 도로로 편입됨
